===============================================================================
 STORE OWNERS — MANUAL ENTRY SHEET
 For: Admin → Stores → Add Store  (type these in by hand; nothing is imported)
 Prepared for the deployed Aquilala system · values valid as of October 2026
===============================================================================

HOW TO USE THIS FILE
  1. Sign in as admin → sidebar → Stores → "Add Store".
  2. Type each owner's block below, section by section, in the same order the
     form shows them.
  3. Submit. The account is created as PENDING: a 6-digit activation code is
     emailed to the address you typed, and the owner sets their own password
     on first sign-in.
  4. Repeat for the next owner.

RULES THE FORM ENFORCES (from AdminStoreController::validateStore)
  * REQUIRED — only four things: Store/Business Name, Owner First Name,
    Owner Last Name, Email. Nothing else blocks the save.
  * FIXED — City and Province are read-only and are overwritten server-side
    to "Bulan" / "Sorsogon". Do not try to change them.
  * BARANGAY — pick from the dropdown only (Bulan's 63 barangays); all three
    below are in that list. Leaving it blank is allowed.
  * PHONE — the "+639" prefix is already there, so type ONLY the 9 digits
    after it. Optional, but it must not be already used by another account.
  * EMAIL — must be new. It is the sign-in name AND where the activation code
    goes, so use an inbox you can actually open (their real email, or one
    you control).
  * Tax ID and Business Registration No. are OPTIONAL — leave them blank
    unless you are holding the owner's real certificate.
  * Legal papers: up to 5 at once, each needs BOTH a type and a file, and the
    type must be picked from the dropdown (free text is rejected). Zero papers
    is fine; more can be filed later from the store's own page.

-------------------------------------------------------------------------------
 AFTER ALL THREE ARE CREATED
-------------------------------------------------------------------------------
  * Each store appears in Admin → Stores with status "pending" until its owner
    signs in, enters the emailed 6-digit code and picks a password.
  * If the activation email does not arrive (sender domain not configured on
    the server yet), the store is still registered — use "Resend Invitation"
    on the Admin → Users list once sending works.
  * Add or remove papers any time: Stores → the store → file paper
    (PDF/JPG/PNG up to 10 MB, one paper per upload).
  * Correct anything later from Stores → Edit. City/Province stay fixed there
    too; everything else stays editable.
